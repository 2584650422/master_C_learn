# C 语言学习代码存档

记录跟随课程学习 C 语言时编写的练习代码。

练习按编号放在不同目录中，每个示例独立保存。当前源文件使用 `.cpp` 扩展名。

## 代码提交

### 使用 VS Code

在左侧“源代码管理”中检查改动，暂存要提交的文件，输入提交说明（例如 `完成数组与函数练习`），然后点击“提交”。需要备份到远程仓库时，再执行“推送”或“同步更改”。

### 使用 Git 命令

在项目目录打开终端：

```sh
git status                     # 查看改动和暂存状态
git diff                       # 查看尚未暂存的改动
git add 018_数组和函数/main.cpp  # 只暂存指定文件
git diff --staged              # 检查本次准备提交的内容
git commit -m "完成数组与函数练习"
```

确认所有待提交文件都需要纳入时，也可以用 `git add -A` 一次暂存全部未忽略的改动。配置了远程仓库后，才需要推送：

```sh
git remote -v                              # 查看是否已配置远程仓库
git remote add origin <远程仓库地址>         # 首次使用时配置，例如 GitHub 仓库地址
git push -u origin main                    # 首次推送当前 main 分支
```

暂存只是选择本次提交包含哪些文件；提交保存在本地；推送才会发送到远程仓库。提交前检查状态和差异，避免把不需要的文件一起保存。
