# C 语言学习代码

这是一个按课程章节整理的编程练习项目，包含基础语法、输入输出、分支与循环、函数、数组、指针以及一些数值练习。每个章节通常有独立的示例程序，适合边看课程边修改和运行。

## 章节目录

| 目录 | 内容 |
| --- | --- |
| `000_hello_world` | Hello World 入门示例 |
| `001_C代码的执行过程` | C 程序的执行过程 |
| `003_常量`–`010_运算符和表达式` | 常量、变量、数据类型、字符、输入输出和表达式 |
| `011_选择结构if`–`013_循环` | 条件选择、`goto` 和循环 |
| `014_函数`–`016_值传递` | 函数、作用域、生存期和值传递 |
| `017_数组`–`020_指针` | 数组、数组与函数、二维数组和指针 |
| `022_指针的传递` | 指针参数与传递练习 |
| `025_水仙花数`–`027_质数` | 水仙花数、完数和质数练习 |

目录编号按课程进度保留，因此编号中有跳号。每个示例目录中的 `main.cpp` 是独立程序，不应把所有示例一次性链接到一起（它们通常各自定义了 `main` 函数）。

## 编译和运行

本机 macOS 可使用 Apple Clang。在终端进入某个示例目录后，例如：

```sh
cd "013_循环"
clang++ -Wall -Wextra -pedantic -g main.cpp -o main
./main
```

也可以在 VS Code 打开项目文件夹，打开要运行的 `.cpp` 文件，再按 `F5` 调试；在行号左侧单击可设置断点。运行需要输入的程序时，请使用 VS Code 集成终端。

## 关于语言扩展名

当前课程文件使用 `.cpp` 扩展名，所以编译器会按 C++ 源文件处理。示例内容以 C 语言基础为主，但若希望严格按 C 编译，应将相应文件保存为 `.c`，并使用 `clang` 而不是 `clang++`。
